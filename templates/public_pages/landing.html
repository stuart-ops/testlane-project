01 • CORE HARDWARE

UGREEN NASync N100

Intel N100, 8GB DDR5, 3.7TB Btrfs storage. Runs the Hermes Docker gateway daemon on local host IP `192.168.1.24`.

02 • ZERO-TRUST NETWORK

Tailscale Mesh Topology

End-to-end WireGuard tunnel. No open inbound ports or router port forwards. Authenticates Stuart's phone, laptop, and NAS.

03 • LOCAL STATE & SYNC

Obsidian + Syncthing Vault

Task state, Kanban boards, and financial logs synchronise directly between phone and NAS with zero cloud intermediary.

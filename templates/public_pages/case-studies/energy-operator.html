Case Study 02

LSE-Listed Upstream Energy Producer — Dynamic Strip DCF Valuation Engine

North Sea Operating Assets — Commodity Valuation

Problem

The v2 monthly workbook model required manual curve updates from ICE and EIA sources. Repricing the DCF for board presentations took hours of data entry and cross-checking. Sensitive production and reserve data could not be exposed to third-party analytics platforms.

Sovereign Solution

LayerImplementation
Brent StripYahoo Finance chart endpoint (BZ=F futures contract chain). Nightly Cloud Run job pulls and validates.
NBP Gas StripDatabento API — ICE UK NBP futures. Usage-priced at ~$0.04/pull, capped at $0.50/night.
Spot BenchmarksEIA Open Data API for public government energy data.
EnginePure Python monthly model: production, hedges, three tax pools (RFCT 30%, SCT 10%, EPL 38%), balance sheet, dividends, DCF. Full run in milliseconds.
ValidationFailed/implausible pulls load nothing. Dashboard keeps last good curve. Flags stale after 4 days.
StorageBigQuery curves, prices, and latest curve views in dedicated analytical dataset.
DashboardFastAPI single HTML page with interactive sensitivity levers: curve shift, price floors, payout ratio, discount rate, drilling toggle.

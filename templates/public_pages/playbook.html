The Playbook

Sovereign Vibe Coding Playbook

The exact infrastructure-as-code stack deployed for every Testlane.ai client. Open, auditable, reproducible from zero.

1. Terraform Infrastructure as Code

Every deployment starts with a single terraform apply. Our module library provides standardised, security-hardened building blocks:

  • cloud-run-service — Serverless container with scale-to-zero, VPC egress, Cloud NAT, and denial-of-wallet caps.
  • cloud-run-job — Scheduled job with Cloud Scheduler trigger for nightly syncs and batch processing.
  • bigquery-dataset — Isolated analytical warehouse with IAM-scoped access per client.
  • cloudflare-perimeter — DNS with Orange Cloud proxy, WAF, and Zero Trust Access gates.

State stored in private GCS bucket. Per-client .tfvars files (never committed to git). Zero click-ops.

# terraform.tfvars — never commit this file project_id = "client-project-123" client_name = "msp-group" service_subdomain = "dash" max_instance_count = 5

2. Cloudflare Zero Trust Perimeter

Every endpoint behind Cloudflare Access with Google SSO:

  • Orange Cloud DNS — All records proxied through Cloudflare for DDoS, WAF, and SSL.
  • Zero Trust Access — OTP challenge before any traffic reaches the backend container.
  • Cf-Access-Authenticated-User-Email — Header validated in application code for defence-in-depth.
  • Fixed Egress IP — Cloud NAT ensures deterministic outbound IP for client allow-listing.

3. Cloud Run Scale-to-Zero Economics

Every service configured with hard caps:

scaling { min_instance_count = 0 # Scale-to-zero: zero idle cost max_instance_count = 5 # Denial-of-wallet: hard ceiling }

Services wake on first request with sub-second cold starts. Monthly cost: £5–£15 for typical deployments. No per-seat licensing. No idle compute charges.

4. DuckDB Local Analytics

For on-premise deployments where cloud warehouses are not appropriate:

  • Zero-config — Embedded analytical SQL engine. No server process. No daemon.
  • File-native — Queries run directly on Parquet, CSV, and JSON files on the NAS filesystem.
  • Columnar engine — Fast analytical queries without indexes or tuning.
  • Complementary — BigQuery for cloud-scale analytics; DuckDB for sovereign, air-gapped deployments.

5. CI/CD Pipeline

Cloud Build trigger on push to main branch:

  1. Docker build from Dockerfile
  2. Push image to Artifact Registry
  3. Deploy Cloud Run service with new revision
  4. Deploy Cloud Run job with updated image
  5. Health check: HTTP 200 on dashboard URL

All secrets in Google Secret Manager. No .env files in build context. No hardcoded credentials.

The Playbook

Sovereign Vibe Coding Playbook

The exact infrastructure-as-code stack we deploy for every client. Open, auditable, reproducible from zero.

Terraform + .tfvars

Every deployment is a single terraform apply. Infrastructure defined in HCL with per-client .tfvars files. State stored in private GCS bucket. Zero click-ops.

Cloudflare Zero Trust

Orange Cloud DNS on every record. Cloudflare Access with Google SSO gates every dashboard before traffic reaches the backend container. WAF rules block common attack patterns.

Cloud Run Scale-to-Zero

min_instance_count = 0 eliminates idle costs. max_instance_count caps prevent denial-of-wallet. Services wake on first request with sub-second cold starts.

DuckDB Local Analytics

Embedded analytical SQL engine for on-premise deployments. Zero-config, zero-server. Queries run directly on Parquet/CSV/JSON files on the NAS filesystem. BigQuery for cloud-scale; DuckDB for sovereignty.
